# 🎓 تربوي بوت (Tarbiwi Bot)
### المكتبة التعليمية التفاعلية الرسمية لدبلومة التأهيل التربوي أون لاين – مجموعة 3

بوت تيليجرام تعليمي احترافي متكامل مبني باستخدام **Python 3.11+**, **aiogram 3**, و **SQLite**، يتيح لأعضاء دبلومة التأهيل التربوي تصفح المناهج الدراسية، الكتب والمراجع، المحاضرات، الملفات والفيديوهات، والبحث الشامل، مع إمكانية مشاركة ورفع المحتوى من جميع الأعضاء، ودعم التخزين والأرشفة الدائمة في تيليجرام، مع لوحة تحكم إدارية متقدمة للمشرفين.

---

## 🌟 أبرز مميزات البوت

1. **القائمة الرئيسية المعتمدة:**
   - 📚 **عرض المنهج الدراسي:** تصفح الكتب ومواد الأيام الدراسية.
   - 🔍 **البحث عن ملف:** بحث فوري وشامل في أسماء المواد، الدكاترة، المحاضرات، التخصصات، الملفات، التصنيفات، والفيديوهات.
   - 📤 **مشاركة ملف جديد:** نظام رفع متكامل متاح لجميع الأعضاء مع دعم الرفع المتتالي.
   - 🔗 **روابط المجموعات المهمة:** استعراض قنوات ومجموعات الدبلومة مع إدارة فورية للروابط.

2. **الجدول الدراسي الدقيق وتوزيع الأيام:**
   - **الأربعاء (5 مواد):** طرق التدريس العامة (أ.د/ محمد عبد الوهاب محمد)، الإدارة والتخطيط (د/ شاذلي يونس علي)، التدريس المصغر (أ.د/ خلف الديب عثمان محمد)، **طرق تدريس (2) - جميع التخصصات**، الصحة النفسية وعلم النفس الاجتماعي (أ.د/ نجلاء محمود رسلان).
   - **الخميس (4 مواد):** التربية الإسلامية (أ.د/ محمود يوسف محمد)، الفكر التربوي الإسلامي (أ.د/ محمود يوسف محمد)، التربية ومشكلات المجتمع (أ.د/ محمد شكري وزير)، علم النفس التعليمي (1) (أ.د/ منال علي الخولي).
   - **الجمعة (3 مواد):** التربية المقارنة (د/ محمد سعد زكي)، الوسائل التعليمية (د/ بسيوني عبد الرحمن العطار)، علم نفس النمو (أ.م.د/ حمدي حامد سالم).
   - **السبت (5 مواد):** المناهج (أ.د/ عصام محمد أبو الخير)، الأصول الاجتماعية والثقافية للتربية (أ.د/ جمال رجب عبد الحسيب)، الأصول الفلسفية للتربية (د/ محمود أحمد حموده)، تاريخ التربية ونظام التعليم (أ.د/ التهامي محمد إبراهيم)، علم النفس التعليمي (2) (أ.د/ أيمن منير الخصوصي).

3. **مادة «طرق تدريس (2)» والتخصصات السبعة (الشرط الحاسم):**
   - مادة رقم 4 يوم الأربعاء حصراً وليست مادة إضافية.
   - تحتوي على مستويات فرعية لـ 7 تخصصات: **تخصص شرعي، رياضيات، علوم، إنجليزي، فرنساوي، اجتماعيات، لغتي**.
   - عزل تام لملفات ومحاضرات وفيديوهات كل تخصص دون أي تداخل.

4. **نظام تعدد الملفات اللامحدود (شرط أساسي):**
   - المحاضرة الواحدة تدعم عدداً غير محدود من الملفات في كل تصنيف:
     1. 🤖 **ملخص AI**
     2. ✍️ **شرح بخط اليد**
     3. 📊 **PowerPoint الدكتور**
   - كل ملف له سجل مستقل في قاعدة البيانات، ولا يتم استبدال الملفات السابقة إطلاقاً عند إضافة ملف جديد.
   - ترقيم الصفحات (Pagination) التلقائي لمنع طول القوائم.
   - إمكانية حذف أو إخفاء ملف منفرد دون التأثير على بقية ملفات المحاضرة.

5. **رفع ملفات متعددة متتالية:**
   - بعد نجاح رفع أي ملف، يظهر للمستخدم زر «📤 رفع ملف آخر لنفس المحاضرة والتصنيف».
   - يحتفظ البوت بالمسار السابق بالكامل ويطلب من العضو فقط: اسم الملف، الملف، ووصف اختياري.

6. **الأرشفة والإشعارات:**
   - توجيه ونسخ الملفات تلقائياً إلى قناة/مجموعة الأرشيف الخاصة بالبوت لحفظها وحفظ `file_id`.
   - إرسال إشعار تلقائي إلى مجموعة الدبلومة الرئيسية عند نشر محتوى جديد.

7. **لوحة تحكم المشرف (Admin Panel):**
   - إدارة المواد وأعضاء هيئة التدريس والتخصصات والمحاضرات.
   - إدارة الروابط والكتب والملفات والفيديوهات.
   - مراجعة اقتراحات المواد المقدمة من الأعضاء واعتمادها أو رفضها.
   - حظر وفك حظر المستخدمين بالمعرف (Telegram User ID).
   - إحصائيات النظام الشاملة وسجل النشاط.
   - تنزيل نسخة احتياطية من قاعدة البيانات SQLite بضغطة زر.

## 🚀 التثبيت والتشغيل المحلي (Local Setup)

1. **انتقل إلى مجلد المشروع:**
   ```bash
   cd tarbiwi_bot
   ```

2. **إنشاء البيئة الافتراضية وتفعيلها:**
   - على ويندوز (Windows):
     ```cmd
     python -m venv .venv
     .venv\Scripts\activate
     ```
   - على لينكس / ماك (Linux / macOS):
     ```bash
     python3 -m venv .venv
     source .venv/bin/activate
     ```

3. **تثبيت الاعتماديات:**
   ```bash
   pip install -r requirements.txt
   ```

4. **إعداد ملف متغيرات البيئة (`.env`):**
   قم بنسخ ملف `.env.example` إلى `.env`:
   ```bash
   cp .env.example .env
   ```
   افتح ملف `.env` واملأ البيانات:
   ```env
   BOT_TOKEN=توكن_البوت_الخاص_بك_من_BotFather
   ADMIN_IDS=معرف_المشرف_1,معرف_المشرف_2
   ARCHIVE_CHANNEL_ID=-1001234567890
   MAIN_GROUP_ID=-1009876543210
   DB_PATH=data/tarbiwi.db
   ```

5. **تشغيل الاختبارات التلقائية للتأكد من سلامة النظام:**
   ```bash
   python tests/test_all_features.py
   ```

6. **تشغيل البوت:**
   ```bash
   python main.py
   ```

## 🌐 دليل الاستضافة والتشغيل الدائم 24 ساعة (Ubuntu Server)

لتشغيل البوت بشكل دائم على خادم سحابي (VPS يعمل بنظام Ubuntu 22.04 أو 24.04):

### الخطوة 1: تحديث السيرفر وتثبيت بايثون
```bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y python3 python3-pip python3-venv git
```

### الخطوة 2: رفع أو استنساخ المشروع على الخادم
ضع مجلد المشروع في المسار: `/opt/tarbiwi_bot`
```bash
sudo mkdir -p /opt/tarbiwi_bot
sudo chown -R $USER:$USER /opt/tarbiwi_bot
cd /opt/tarbiwi_bot
# انسخ ملفات المشروع هنا
```

### الخطوة 3: إنشاء البيئة وتثبيت المكتبات
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### الخطوة 4: ضبط الإعدادات (.env)
```bash
cp .env.example .env
nano .env
# أدخل التوكن ومعرفات المشرفين وقناة الأرشيف ثم احفظ الملف (CTRL+O ثم Enter ثم CTRL+X)
```

### الخطوة 5: تفعيل خدمة `systemd` للتشغيل الدائم وإعادة التشغيل التلقائي
الملف جاهز داخل المشروع باسم `tarbiwi_bot.service`. قم بنسخه لمجلد خدمات النظام:
```bash
sudo cp /opt/tarbiwi_bot/tarbiwi_bot.service /etc/systemd/system/tarbiwi_bot.service
sudo systemctl daemon-reload
sudo systemctl enable tarbiwi_bot.service
sudo systemctl start tarbiwi_bot.service
```

### الخطوة 6: مراقبة حالة البوت وسجل التشغيل
- **التحقق من حالة الخدمة:**
  ```bash
  sudo systemctl status tarbiwi_bot.service
  ```
- **عرض السجلات المباشرة (Live Logs):**
  ```bash
  journalctl -u tarbiwi_bot.service -f
  ```
- **إعادة تشغيل البوت عند تحديث الكود:**
  ```bash
  sudo systemctl restart tarbiwi_bot.service
  ```

## 📌 خطوات يحتاج إليها المستخدم (تدخل بشري)

1. **إضافة البوت إلى قناة/مجموعة الأرشيف:**
   - أنشئ قناة أو مجموعة خاصة (Private Channel) باسم مثلاً `أرشيف تربوي بوت`.
   - أضف البوت فيها وقم بترقيته إلى **مشرف (Admin)** مع منحه صلاحية **نشر الرسائل والملفات**.
   - انسخ معرّف القناة (ID يبدأ عادة بـ `-100...`) وضعه في متغير `ARCHIVE_CHANNEL_ID` في ملف `.env` أو اضبطه من لوحة المشرف في البوت.
2. **إضافة البوت إلى مجموعة الدبلومة الرئيسية (اختياري للإشعارات والتحقق):**
   - أضف البوت لمجموعة الدبلومة.
   - ضع معرّف المجموعة في متغير `MAIN_GROUP_ID`.
   - يستطيع البوت إرسال إشعار تلقائي للأعضاء فور قيام أي زميل بمشاركة ملف أو فيديو جديد.
3. **تعيين المشرفين:**
   - احصل على معرّفك الرقمي عبر بوت [@userinfobot](https://t.me/userinfobot) وضعه في `ADMIN_IDS` ليفتح لك البوت زر «⚙️ لوحة تحكم المشرف».
